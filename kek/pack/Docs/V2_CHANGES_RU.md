# Изменения графики v2

Этот файл и AI_INTEGRATION_RU.md уточняют графику относительно исходного обзора и списка ресурсов. Правила игры, которых изменения не касаются, сохраняются.

- Стенки заменены полными квадратами 64×64: 12 вариантов, каждая занимает одну клетку и имеет квадратный коллайдер. Узких 24px балок больше нет. Из блоков строятся формы.
- Полностью заменены четыре схемы арен: дворы, смещённые проходы, массивные острова и обходы. Координаты указаны клетками. Проходимость проверена для квадратных роботов от 1×1 до 5×5; в Unity ещё нужна проверка управления и боя.
- Поверхности и средние участки рамок модулей очищены от случайных пятен и рваных полос. Повреждения добавляются отдельными слоями. Командные версии сохраняют один силуэт; вместо бирюзового у врага красный.
- Нарисованы цифры 0–9, × и +: 12 отдельных PNG 24×28, готовые счётчики ×0…×25. Они заменяют шрифт только в счётчике количества.
- Клавиши W/A/S/D/Esc имеют свои нарисованные буквы и два состояния. Поверх них не добавлять текст m6x11. Остальные подписи остаются выбранным шрифтом.
- По 16 отличающихся тайлов пола, арены и коврика; по 16 вариантов каждой из четырёх сторон деревянной рамки. Края совместимы, соседние варианты не повторяются. Seed и готовая раскладка сохранены.
- Full HD превью собраны прямо в 1920×1080 из финальных PNG. Модули вставлены 1:1, без пикселизации готового кадра. Полные карты 4096×2304 также сохранены 1:1; маленькие UI-карточки отдельно уменьшены до своего размера.
- Сохранены анимации, направления турелей, метки дул, 9-slice и исходный m6x11cyrillic.ttf. Упакованные листы пересобраны из новых файлов.

## Перенос из v1

Замени папку RobotArenaArt целиком, сохранив собственный игровой код отдельно. В новый проект лучше импортировать v2 сразу. В существующем проекте держи резервную копию: здесь нет .meta GUID из твоего Unity-проекта. При замене с сохранением .meta восстанови необходимые ссылки и повторно импортируй текстуры.

Обнови чтение arenas.json: теперь occupied_cells и wall_variants вместо segments. Размер клетки 64, начало площадки в table_rect. Не используй wall_visible_thickness_px из старого формата. Для нового кода выбирай блоки из wall-blocks.json; старые wall_* — лишь совместимые копии.

Для вариативной поверхности используй tile-variants.json. Для кастомных чисел — counter-glyphs.json. Для клавиш — keycaps.json. Числа должны собираться в строку из спрайтов; состояния клавиш меняются по вводу.

## Проверка и ограничения

Tools/validate_pack.py проверяет размеры, альфу, цвета команд, метки дул, кадры, точность 9-slice, содержимое атласов, карты, варианты тайлов и совпадение реальных PNG с превью. Результат — Metadata/validation.json. В пакете не выполнен запуск Unity, проверка Editor-скрипта в установленной версии, игрового баланса и устройств ввода.
