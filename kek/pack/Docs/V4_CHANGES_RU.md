# Изменения v4 — прежние пропы, более частая расстановка

Используются точные небольшие спрайты Props из v2, без перерисовки и изменения разрешения. Большая мебель v3 отменена. Верстаки 128×64 и 256×64, вертикальный 64×128, шкаф и лоток 128×64, остальные предметы 64×64. Масштаб 1. props.json содержит размеры и SHA-256 исходных PNG.

В новой расстановке 96 предметов вокруг стола и 49 инструментов на верстаках. Рисовать по layer, дочерние инструменты определяются parent_id. Не считать такие перекрытия ошибкой, не добавлять им игровую коллизию.

Сплошные стенки, тихие пол и поверхность арены, разметка и ровный бортик сохранены. Игровая область по-прежнему 60×32 клетки. Сократился только пустой внешний пол: мир 4352×2448, table_rect [256,192,3840,2048]. Для размещения всегда читай координаты из arenas.json версии 4.

Больших PNG из Props/Large в рабочем наборе больше нет. Модули, красная команда, анимации, шрифт, custom цифры/клавиши и 9-slice сохранены. Превью собираются из настоящих файлов 1:1, без дополнительной пикселизации.

Для переноса обнови Assets/RobotArenaArt, arenas.json, props.json и связанные Config. Сохрани собственный код и Unity .meta. Сначала читай AI_INTEGRATION_RU.md; старые документы V2/V3 оставлены как история и не переопределяют v4.

В этой правке новые изображения генератором не создавались: использованы прежние готовые PNG и изменена расстановка. Исходники генерации предыдущих версий сохранены в SourceSheets, включая отменённый лист большой мебели; не импортировать их вместо игровых файлов.

Проверки файлов, стыков, координат и перекрытий выполняет Tools/validate_pack.py. Unity и игровой баланс отдельно проверяются в проекте.
