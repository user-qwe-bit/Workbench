# Workbench

Игра для Windows x64 на Unity 6000.6.6f1. Основной язык — русский.

## Запуск

Откройте `Builds/Windows/Workbench.exe`. В переносимом архиве EXE находится в папке `Workbench`.
Распакуйте всю папку: рядом с EXE нужны `Workbench_Data`, `UnityPlayer.dll`, `MonoBleedingEdge` и другие файлы комплекта. Unity, отдельный Python и интернет для игры не требуются. Внутри сборки находятся обе модели распознавания и нативные библиотеки.

## Управление и цикл

- Все десять уровней открыты. Выберите карточку, изучите пять задач и перейдите в мастерскую.
- Перетащите детали из запаса на поле 5×5. Батарея даёт 5 энергии. Детали соединяются сторонами, не вращаются. Одно ядро обязательно; без оружия можно таранить.
- Перетащите установленную деталь обратно в запас или снимите ПКМ. Escape отменяет перенос.
- Нажмите карточку схемы и выберите любую из четырёх арен. СТАРТ проверяет ядро, питание, связность, место и доступный запас.
- В бою: WASD — движение; мышь — прицел; ЛКМ — стрельба; ПКМ — щит; Escape — пауза.
- Щит работает 3 секунды и готов снова через 30 секунд от активации. Круг на модуле показывает реальную готовность. Поставьте щит с защищаемой стороны робота.
- Победа наступает при разрушении ядра врага. Время второй звезды не ограничивает длительность боя. Звёзды объединяются между успешными попытками.
- Повтор возвращает исходную предбоевую сборку. Боевые повреждения не расходуют запас деталей навсегда.

Окно рассчитано на 1920×1080; интерфейс сохраняет область 16:9 при изменении окна. Отдельной дополнительной пикселизации экрана нет.

## Голос и камера

В НАСТРОЙКАХ включите нужную функцию, выберите устройство и нажмите ГОТОВО. По умолчанию обе функции выключены. Статусы видны в настройках и в мастерской. Голос работает локально через Vosk, рука — через MediaPipe Hand Landmarker.

Команды: «Начать бой» в мастерской, «Пауза» в бою, «Продолжить» на паузе. Голосовой старт проходит те же проверки, что кнопка.

В мастерской указательный палец ведёт курсор. Сведите большой и указательный пальцы для захвата детали, разомкните для отпускания. Щипком можно нажимать кнопки. При длительной потере руки перенос отменяется с возвращением исходной детали. В настройках есть зеркало, настоящие названия камер, пункт «ПО УМОЛЧАНИЮ» и порог щипка. Начните с автоматического выбора, ровного освещения и полностью видимой кисти.

Если устройство недоступно, проверьте его подключение, разрешение для настольных приложений в параметрах Windows и занятость другим приложением. Для микрофона можно выбрать другой вариант того же устройства; автоматический режим пробует доступные драйверы и частоты записи. Для камеры поддержаны DirectShow и Media Foundation. Клавиатура и мышь работают при выключенных или недоступных устройствах. Видео и звук не сохраняются и не отправляются в сеть.

**Оставшаяся ручная проверка:** пользователь решил самостоятельно проверить веб-камеру. Ранее камера в автоматической проверке не открылась. Новое перечисление устройств определяет HD User Facing; живой видеопоток оставлен для самостоятельной проверки пользователя. Нативная модель распознаёт тестовую фотографию, но живое управление рукой здесь не подтверждено. Микрофон открывается; акустические тесты выполнены для «Пауза» и «Продолжить», а живая речь и запись «Начать бой» не проверены. Все три игровых действия и запрет неверного голосового старта проверены в Windows Player.

## Сохранения

`%USERPROFILE%/AppData/LocalLow/Workbench/Workbench/workbench-save.json`

При первом запуске автоматически копируется прежнее сохранение из `LocalLow/Workbench/Workbench Arena`, если нового файла ещё нет. Старый файл сохраняется.

Сохраняются отдельные сборки и схема каждого уровня, накопленные звёзды, громкость, устройства и подсказки. Запись атомарная, предыдущая версия остаётся в `.bak`. В тестовом режиме используется отдельная папка `Builds/Windows/TestResults/SmokeSave`, обычные сохранения не меняются.

## Сброс достижений

В НАСТРОЙКАХ нажмите **СБРОСИТЬ ПРОГРЕСС** и подтвердите действие. Обнулятся звёзды всех десяти уровней; сборки роботов, схемы и настройки сохранятся. «ОТМЕНА» или Escape закрывают подтверждение без изменений.

## Проект и баланс

Откройте корень проекта в **Unity 6000.6.6f1**, сцена `Assets/Workbench/Scenes/WorkbenchArena.unity`. Сцена и префабы уже созданы. Играть можно без ручного связывания компонентов.

Основные числа, уровни, задачи и схемы — `Assets/Workbench/Resources/GameData.json`; генератор исходных данных — `Tools/prepare_content.py`. Решения описаны в `Docs/BALANCE_RU.md`. Меню Unity `Workbench` содержит подготовку проекта, критические проверки и Windows-сборку. Подготовка заново создаёт генерируемые сцену/префабы, поэтому собственные правки генератора следует вносить в код до повторной генерации.

Рендер — Built-in, без освещения и постобработки, Gamma, Point, FullRect, 64 PPU. Unity Hub показывает предупреждение об устаревании этого конвейера; это ожидаемо. На закреплённой версии рендер и Windows Player проверены. Unity сохраняет поддержку Built-in в линейке Unity 6: https://docs.unity.com/en-us/engine/6000.6/manual/render-pipelines/built-in-render-pipeline

Подробности проверок — `Docs/VERIFICATION_RU.md`, состояние — `DEVELOPMENT_STATUS.md`, авторы и лицензии — `THIRD_PARTY_NOTICES.md` и `Licenses`.

## Обновление по замечаниям

Обмен и замена деталей, новый HUD и шкалы, переходы, частицы, коннекторы, плавное движение и урон стен, настройка подсказок описаны в `Docs/POLISH_RU.md`.

## Последнее обновление

В HUD оставлен один крупный таймер прошедшего времени. Звезда и время цели убраны; условие второй звезды по-прежнему указано в заданиях уровня. Движение роботов не менялось.

При каждом запуске открывается предыстория; её можно пропустить. Обучение в конструкторе повторяется до первой победы в текущем сеансе, а пояснения специальных модулей — один раз за сеанс для каждого типа. Старые флаги завершения не отключают обучение при новом запуске. Звёзды, сборки и настройки сохраняются.
