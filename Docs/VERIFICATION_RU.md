## Известные ограничения и ручная приёмка

1. Пользователь сообщил, что веб-камера есть, и решил проверить её самостоятельно. Ранее среда автоматической проверки не смогла открыть камеру ни через DirectShow, ни через Media Foundation. В этой версии нативное перечисление успешно прочитало название HD User Facing без открытия устройства; живую камеру по договорённости оставили для проверки пользователя. **Живое управление рукой не отмечено пройденным.** Реальная модель и обработка отказа проверены, имитации распознавания в игре нет.
2. Живая речь пользователя и акустический образец «Начать бой» не проверены. Для этой фразы нет готового тестового WAV; запуск генератора был отклонён PowerShell ExecutionPolicy, политика не менялась. В отчёте распознавания этот случай отмечен `not_run`, а не успешным тестом. Общий игровой обработчик трёх команд проверен.
3. Модельные пилоты подтверждают достижимость задач, но не заменяют человеческий плейтест. Точность распознавания зависит от микрофона, освещения, положения кисти и шума. Производительность проверялась на текущем компьютере с RTX 3050 Laptop; отдельная матрица другого оборудования не выполнялась.
4. Предупреждение Unity Hub об устаревающем Built-in ожидаемо; версия движка зафиксирована. При переходе на будущую версию потребуется повторная проверка рендера.
